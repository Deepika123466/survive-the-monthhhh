# Survive the Month — Smart Budget Planner

A responsive personal finance dashboard built for the FrontendArena “Survive the Month” challenge.

## Stack
- React + Vite
- Recharts for interactive charts
- Lucide React icons
- Custom responsive CSS

## Features
- ₹10,000 monthly budget and remaining balance
- Add and delete transactions
- Daily allowance and 30-day spending forecast
- Category breakdown chart and spending trend chart
- Savings goal tracker
- Subscription/recurring expense manager
- What-if spending simulator with live calculations
- Responsive mobile, tablet and desktop layouts

## Run locally
1. Install Node.js (LTS).
2. Extract the ZIP and open this folder in VS Code.
3. In a terminal, run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Before submitting
- Test the app at mobile and desktop widths.
- Try adding/deleting expenses and changing the savings goal.
- Deploy to a public URL (for example, Vercel or Netlify) and submit that URL in FrontendArena.
- Verify the challenge's submission form requirements and that the deployed URL is accessible without login.

## Note
This is a frontend prototype using in-memory state. Refreshing the page resets demo data. For a stronger production version, add localStorage or a backend and persistent data storage.
